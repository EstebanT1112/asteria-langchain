# Manual de mantenimiento preventivo del XR-7

## Frecuencia de inspección

El robot industrial XR-7 debe someterse a una inspección preventiva cada 30 días.

## Alcance de la inspección

La revisión comprende una inspección visual, la comprobación de fijaciones y el registro de anomalías detectadas. Este documento académico no proporciona instrucciones para reparar ni operar equipos reales.
